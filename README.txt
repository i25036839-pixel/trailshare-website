TrailShare — ICT2215 Website Project
====================================

HOW TO OPEN
1. Unzip the folder.
2. Double-click index.html in Chrome or Edge.
3. The top navigation links connect all four pages.
4. All scenic artwork is included locally and works offline.
5. The Google Fonts request is optional; the site falls back to Arial when offline.
6. The Hiking Guide embeds a YouTube video, which needs internet to play.

PAGES
index.html — Home, About, Featured Trails
explore.html — Route cards, difficulty filters and route detail sections
share.html — Demonstration trail submission and contact forms
 guide.html — Beginner tips, equipment, safety, embedded video, checklist

TECHNOLOGY
HTML5: page structure, sections, links, forms, embedded video
css/style.css: shared colour palette, typography, cards and responsive layout
js/main.js: mobile menu, route filters, non-sending form notices

IMPORTANT
This is a FRONT-END DEMONSTRATION. No submitted data is stored.
Images in images/ are original computer-drawn scenic illustrations, NOT photographs
of the places named in the route cards. Replace them with your own hiking photos
or properly licensed photos, including attribution, before claiming they show
specific real locations.
Trail status, distance, hiking times and difficulty must be verified locally.
Avoid suggesting restricted or dangerous trails as suitable for beginners.

EASY LIVE CHANGES FOR DEMONSTRATION
1. Change --forest colour at top of css/style.css.
2. Change the <h1> text inside index.html.
3. Change a featured route name inside explore.html.
4. Add a new navigation link to header on each page.

Wireframe PDF is supplied separately in the conversation.
